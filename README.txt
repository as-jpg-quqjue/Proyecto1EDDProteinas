Este programa fue diseñado para poder simular  Redes de Interacción Proteína-Proteína (PPI), 
que se realizan utilizando grafos en Java, con la capacidad de detectar las proteinas mas importantes
o los hubs para ver como cambia el complejo al activarlas o desactivarlas.

El programa tiene la capacidad de cargar, leer y guardar un archivo .csv que representa el estado del compuesto de proteinas,
utilizar el algoritmo Djikstra para encontrar la ruta mas corta de una proteina a otra, apagar o encender proteinas y crear
o remover conexiones PPI y utilizar BFS para identificar los nodos que trabajan aisladas de las demas.
